# 企业客户接入实测 — 2026-09-13

结论：基础连接可用，暂不建议直接开放企业和投资人自助试用。应先修复官方示例失败及文档契约差异，再完成真实动作闭环和可靠性验收。

## 方法与范围

使用现有分配给 Phonebase 02 的客户凭证，经公网 https://phonebase-station.videocoding.ai 访问真实设备；从公开站点下载文档、MCP 独立客户端及 Node 示例。凭证未写入报告。MCP 在临时目录通过真实 stdio 协议客户端运行，并核对发布文件 SHA-256。没有发送物理移动；仅执行 wait。测试环境已有 Node，不代表客户全新安装环境，也未验证所有商业 MCP 宿主。

证据：`.runtime/enterprise-evaluation/results.json`、`published-example-result.json`、下载的公开文档与客户端。数据仅代表本机当前网络短时测试。

## 确认的问题

1. **发布前必须修：网关丢失截图时间戳。** API 上游生成 X-Phonebase-Captured-At，但 remote_gateway.ts 的响应头白名单只转发帧序号、宽、高。线上官方 remote-inspect.mjs 因缺失头拒绝截图；MCP 返回 capturedAt: 0，造成表面成功但元数据错误。应同时修复转发和客户端缺失值处理，并复测公开下载物。
2. **文档契约需要修正：并非每个动作都有 receipt。** wait 实测同步返回 completed、无 result.receipt；相同 idempotencyKey 重复提交以及更改等待时长均 200。源码表明 status 也同步完成。公开动作指南统一要求读取 receipt.id，却未说明这些例外。不能据此声称物理动作去重也失败；本轮未执行该验证。
3. **线上接入说明与短码方案不同步。** 公开 quickstart 仍说明 access code 是包装信息、不能直接作 Bearer key，但本次短码作为 Bearer 已成功。客户需要清楚区分当前短密钥与兼容旧邀请格式。
4. **MCP 错误返回不利于自动恢复。** 越权只有错误文本，没有结构化 HTTP 状态和稳定错误码；客户 agent 难以可靠区分权限、断线和设备忙。
5. **MCP 安装仍有明显操作负担。** 下载文件、确认 Node 版本、填写绝对路径、三个环境变量、修改宿主配置并重启。协议工具调用已验证；不能把它等同于商业宿主的一键接入验收。

已检查公开站点部署的 dashboard-content-CHlT74Dx.js：悬停权限包含 endpoint.remote !== true。本地源码也有对应保护。因此当前远程控制不会逐条发送鼠标悬停移动。公网有明显额外往返延迟；未来若启用连续跟随，应将光标显示留在客户端、采用只保留最新目标的控制通道并防止旧目标排队。实际参数需单独测控制链路，不能用列表请求推算。

真实体验：REST 的凭证和设备读取路径比较直接，但官方示例第二步截图失败会立即削弱信任；MCP 工具能调用，但安装和故障解释仍需要工程师协助。目前适合安排有人陪同的技术演示，尚不足以称为自助企业试用已验收。

## 修复与复测（同日）

- 公网网关转发并通过 CORS 暴露截图时间戳；线上原 Node 示例已能取得有效 capturedAt 和图像。MCP 缺失任何关键帧元数据时明确报 INVALID_FRAME_METADATA，不再把缺失值转换成 0。
- status/wait 创建可查询的持久回执。并发同键同参数共享回执；同键不同参数返回 409 IDEMPOTENCY_CONFLICT。新增回执保存解析后的动作指纹；历史无指纹回执只能核对动作类型，不能承诺历史参数级冲突检测。
- MCP 接受调用者提供的 idempotencyKey，保留 HTTP 状态与错误码；执行失败或等待超时返回 isError。已通过独立客户端协议测试。
- Camera Dashboard 使用当前画面的尺寸与帧序号；服务端统一将相机像素映射到屏幕坐标后转换至机械坐标，避免套用 mirror 的元数据。忙碌状态不再触发自动标定弹窗，控制开关不因设备执行动作而反转。
- Phonebase 02 旧相机角点与当前画面不一致。以同步 HD/Camera 图像匹配得到 192 个内点，平均拟合误差 0.944 px；留出匹配验证中位误差 1.288 px（50 个候选留出匹配中 30 个落在 4 px 内，其余包含描述子误匹配）。只更新该设备相机角点，保留机械点、行程与深度限制，保存原配置备份。此数值是视觉配准误差，不是实际触控误差。
- 真实公网客户 API：手机 Home → Camera 帧中天气图标点击 → 完成回执 → HD 截图确认天气已打开。真实 MCP：Home → 最新 HD 帧 → Safari 点击 → 完成回执 → 截图确认 Safari 已打开。
- 额外发现：150 ms 的触底停留可能被本机 iPhone 判成长按；40 ms 默认点击成功。durationMs 是机械停留时间，不能等同于手机检测到的总接触时间。尚未标定所有深度/时长组合。
- 镜像测试过程中发生过一次离线并自动恢复；恢复后的 60 次、约 60 秒采样全部在线，最大观测帧龄 215 ms。不能据此声称长期断线问题已消除。
- 回归：TypeScript 相关自动测试 121 项、Python 25 项、MCP 协议 4 项、文档/HTML 16 项通过；TypeScript 类型检查通过。协议/驱动单元测试使用隔离 fixtures，真实动作结果单独记录。

剩余发布边界：本次可确认连接契约修复及有限真实任务成功；尚未完成九点触控误差测量、所有点击时长、多人并发长时间压力、商业 MCP 宿主安装矩阵及小时级 USB 恢复验收，不能称“没有任何问题”。
